Built using PyTorch and Gymnasium, this code is heavily inspired by the CleanRL library and is designed to be highly readable and easy to tweak.he script automatically tracks your agent's performance metrics using TensorBoard.Before running the code, you need to install a few required Python packages. 
You can do this easily by opening your terminal and running pip install torch numpy gymnasium tyro tensorboard wandb cleanrl.Note that the cleanrl package is required here specifically to import utility helpers for the Replay Buffer and evaluation steps.Running the agent is incredibly straightforward. 
To start training on the default environment (CartPole-v1) with the default hyperparameters, just run python dqn.py. Because the code uses tyro for configuration, you can easily change settings directly from the terminal without ever editing the Python file.
While your agent is learning, you can easily monitor its progress. The script automatically saves training data to a runs/ folder, which you can view by running tensorboard --logdir runs in a new terminal window and visiting the provided local web address. Best of all, once the training completes, the script will automatically run a custom inference loop to test the agent for three episodes. It will record these final test runs and save the .mp4 files directly into a videos/ folder, so you can sit back and watch your fully trained AI play the game.
